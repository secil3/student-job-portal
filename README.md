Student Job Portal
 — Overview
Student Job Portal is a web-based application that connects students with employers offering job and internship opportunities. The platform supports multiple user roles and provides a complete workflow for job posting, application, and management.
This project was developed as part of a Software Engineering course, following Agile development principles, and finalized as a functional Minimum Viable Product (MVP).

Purpose
* Help students find and apply for job and internship opportunities
* Allow employers to post job listings and manage applications
* Ensure system reliability through administrative moderation
* Apply software engineering and Agile development concepts in practice

 Technologies Used
 
- Frontend
* React
* React Router
* CSS
  
- Backend
* Node.js
* Express.js
* JWT Authentication
  
- Database
* MySQL
  
- Tools
* Git & GitHub
* Trello (Project Management)
* Jest (Unit Testing)
* Postman (API testing and request validation)


User Roles & Main Features
 Student
* Register and log in
* Edit profile information
* Upload and manage multiple resumes
* Browse and filter job listings
* Apply for jobs and track application status
  
 Employer
* Register and log in
* Create and manage job postings
* View student applications
* Accept or reject candidates
  
 Admin
* Verify employer accounts
* Remove inappropriate job postings
* View and monitor all registered users

Authentication & Security
* JWT-based authentication
* Role-based access control
* Protected routes for sensitive actions

Testing
Unit testing was implemented for the authentication module, which is a critical part of the system.
* Testing framework: Jest
* Login and registration scenarios were tested
* Core authentication logic was validated for MVP readiness


How to Run the Project

Backend
cd  student-job-portal/backend
npm install
npm start

Frontend
cd student-job-portal
cd student-job-portal-frontend
npm install
npm run dev
