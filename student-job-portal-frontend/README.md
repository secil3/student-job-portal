# Student Job Portal Frontend

This directory contains the React and Vite frontend for Student Job Portal. It includes the public authentication screens and the role-based student, employer, and admin interfaces.

For prerequisites, environment setup, MySQL initialization, backend startup, frontend commands, testing, and known MVP limitations, see the [project README](../README.md).

Common frontend commands:

```bash
npm install
npm run dev
npm run lint
node --test src/__tests__/*.test.js
npm run build
```
